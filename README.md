# Sci-M.5 Knowledge Hub (ศูนย์รวมความรู้วิทยาศาสตร์ ม.5)

สื่อการเรียนรู้และทบทวนเนื้อหาวิชาวิทยาศาสตร์ระดับชั้นมัธยมศึกษาปีที่ 5 ในรูปแบบ Single-page Application (SPA) ที่ทันสมัย สวยงาม และถูกต้องตามหลักสูตรแกนกลาง สสวท.

> **พัฒนาเว็บไซต์โดย นักเรียนห้องเรียนพิเศษวิทยาศาสตร์พลังสิบ ชั้นมัธยมศึกษาปีที่ 5**
> 1. นาย สิปปกร ทองไสล
> 2. นางสาว ญาณิดา วารี
> 3. นางสาว ปิยะธิดา วรรณทวี
> 
> *โครงงานการศึกษาค้นคว้าด้วยตนเอง (Independent Study - IS) ครูที่ปรึกษา: ครูสุชาติ*
> 
> *"เว็บไซต์นี้จัดทำขึ้นเพื่อเป็นสื่อประกอบการเรียนรู้และทบทวนเนื้อหาวิชาวิทยาศาสตร์ระดับชั้นมัธยมศึกษาปีที่ 5"*

---

## 🌟 จุดเด่นของเว็บไซต์ (Key Features)

1. **ครบถ้วนตามหลักสูตร สสวท. ทั้ง 2 ภาคเรียน รวม 27 บทเรียนมาตรฐาน:**
   - **ชีววิทยา (Biology):** 10 บทเรียน (เทอม 1: 5 บท, เทอม 2: 5 บท)
   - **เคมี (Chemistry):** 5 บทเรียน (เทอม 1: 3 บท, เทอม 2: 2 บท)
   - **ฟิสิกส์ (Physics):** 6 บทเรียน (เทอม 1: 3 บท, เทอม 2: 3 บท)
   - **โลก ดาราศาสตร์ และอวกาศ (Earth, Astronomy & Space):** 6 บทเรียน (เทอม 1: 2 บท, เทอม 2: 4 บท)

2. **หน้ารายละเอียดบทเรียนเชิงลึก ครบทั้ง 9 หมวดหมู่วิชาการ:**
   - 1. ภาพรวมของบทเรียน (Overview)
   - 2. จุดประสงค์การเรียนรู้ (Learning Objectives)
   - 3. สรุปเนื้อหาสำคัญ (Key Concepts & Theories)
   - 4. คำศัพท์ทางวิทยาศาสตร์ (Vocabulary ภาษาไทย-อังกฤษ และคำนิยาม)
   - 5. สูตรและสมการที่สำคัญ (เรนเดอร์ด้วย KaTeX สวยงาม คมชัด)
   - 6. คำอธิบายตัวแปรและหน่วย (SI Units)
   - 7. ตัวอย่างการประยุกต์ใช้ในชีวิตประจำวัน (Real-world Applications)
   - 8. จุดเน้นที่ควรจำก่อนสอบ (Exam Pitfalls & Tips)
   - 9. แหล่งอ้างอิงวิชาการ (พร้อมลิงก์ สสวท. https://www.ipst.ac.th/educationlevel/m5)

3. **คลังแบบทดสอบวัดผลสัมฤทธิ์ทางการเรียน 135 ข้อ (5 ข้อต่อบทเรียน):**
   - คำถามปรนัย 4 ตัวเลือก ตรงตามเนื้อหา ม.5
   - ระบบตรวจคะแนนอัตโนมัติ คำนวณเปอร์เซ็นต์ และจัดระดับผลสัมฤทธิ์
   - มีเฉลยและคำอธิบายทางวิชาการอย่างละเอียดทุกข้อ
   - เอฟเฟกต์เฉลิมฉลอง (Confetti Animation) เมื่อทำคะแนนได้ $\ge 80\%$
   - บันทึกสถิติคะแนนล่าสุดและประวัติการทำข้อสอบ

4. **แดชบอร์ดความก้าวหน้าการเรียนรู้ (Learning Progress Dashboard):**
   - แถบแสดงความก้าวหน้าโดยรวมและแถบความก้าวหน้าแยกตาม 4 สาขาวิชา
   - บันทึกสถานะ "อ่านแล้ว" และประวัติคะแนนลงใน **LocalStorage** อัตโนมัติ ข้อมูลไม่สูญหายเมื่อปิดเบราว์เซอร์
   - ปุ่มรีเซ็ตข้อมูลความก้าวหน้าพร้อมระบบยืนยัน

5. **ระบบค้นหาและกรองข้อมูลแบบ Real-time:**
   - ค้นหาได้ทันทีจากชื่อบทเรียน (ไทย-อังกฤษ), สาขาวิชา, แท็ก, หรือเนื้อหา
   - สลับดูภาคเรียนที่ 1, ภาคเรียนที่ 2 หรือทั้งหมดได้เพียงคลิกเดียว

6. **รองรับ Dark Mode / Light Mode สมบูรณ์แบบ:**
   - สลับธีมมืดและสว่างได้อย่างลื่นไหล พร้อมบันทึกการตั้งค่าลงเครื่อง

7. **100% Offline-Capable & Zero-Dependency:**
   - รวมไฟล์ไลบรารีที่จำเป็นไว้ในโฟลเดอร์ `assets/vendor/` ทำให้เปิดใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## 🚀 วิธีการเปิดใช้งานเว็บไซต์

คุณสามารถเปิดใช้งานเว็บไซต์ได้ 2 วิธีตามความสะดวก:

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์ได้ทันที (แนะนำ - สะดวกที่สุด)
1. เปิดโฟลเดอร์โครงงาน `ไอเอสครูสุชาติเว็ปไซต์`
2. ดับเบิลคลิกที่ไฟล์ **`index.html`**
3. เว็บไซต์จะเปิดขึ้นบนเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Firefox, Safari) ทันที และสามารถใช้งานได้ครบทุกฟังก์ชันโดยไม่ต้องติดตั้งโปรแกรมใดๆ เพิ่มเติม

### วิธีที่ 2: รันผ่าน Local Web Server (Node.js)
หากเครื่องของคุณมี Node.js ติดตั้งอยู่ สามารถรันเซิร์ฟเวอร์จำลองเพื่อทดสอบประสิทธิภาพได้ดังนี้:
```bash
# สั่งรันเซิร์ฟเวอร์
npm start
# หรือ
node server.js
```
จากนั้นเปิดเบราว์เซอร์แล้วไปที่: **`http://localhost:3000`**
